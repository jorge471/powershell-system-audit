# PowerShell System Audit

A simple PowerShell script that gathers basic Windows system information.

## Features

- Displays computer name
- Shows Windows version
- Lists IPv4 addresses
- Shows top CPU-consuming processes
- Displays disk usage information

## Usage

Run the script in PowerShell:

```powershell
.\system_audit.ps1
```
